## Штатная возможность Dump на USB

В ресурсах English.xml есть USB Upgrade, Upgrade Type, Dump, Dump successfully!. Русские соответствия: «Обновлениe по USB», «Тип режима», «Сбросить», «Dump сохранён!». Перевод Dump как «Сбросить» неоднозначен: нельзя путать эту опцию с заводским сбросом.

Это не вывод только по строке: в CK610-коде инициализации меню инструкция LRW по 0x9002F726 загружает массив вариантов `[USB Upgrade,Dump]` (строка 0x904C0B40), который сохраняется в структуре элемента меню. У этого элемента установлен callback 0x9002E104. По 0x9002E796 загружается `dump_all.bin` (0x904C08F8) для построения имени файла; ещё одна ссылка есть по 0x9002F140.

Пользователь подтвердил на экране режим «Сбросить», раздел «Все» и путь `/mnt/usb01`, затем выполнил экспорт. Полученный файл проверен: BOOT и все кодовые/ресурсные разделы совпадают с заводским BIN; DATA отличается и сохранён. Экспорт заканчивается на `0x3F0000`, не включает последние 64 КиБ AD. Подробности — в [USB_DUMP_RU.md](USB_DUMP_RU.md). USB-копия сама по себе не подтверждает способ восстановления не загружающегося устройства.
