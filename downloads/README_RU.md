В архиве находятся первоначальные материалы, исходники, инструменты, тесты, отчёты, ресурсы интерфейса, BAT-сборка для Windows 10/11 и инструкция `START_HERE_RU.md`.

Распакуйте весь архив, установите Python 3.12 с Python Launcher и выполните `build.bat`. В рабочей копии пройдены 56 тестов. Предыдущий пакет проверен после чистой распаковки; пользователь подтвердил успешное завершение предыдущего BAT на своём Windows. Текущая версия повторно собрана в Linux.

Обновление: независимая CRC заголовка таблицы разделов подтверждена исполнением оригинального кода eCos. Добавлен аудит реальной recovery-функции загрузчика, её цикла записи и недостаточного барьера длины после чтения файла. Добавлен расчёт диапазонов штатного USB-обновления: вариант «Все» включает BOOT и DATA. Подробности — в `reports/UPGRADE_RECOVERY_RU.md` и `reports/USB_UPDATE_RU.md`. Сохранены анализатор USB-дампа и 224-байтный CK610-finalizer инициализации меню. Загруженный пользователем дамп и содержимое его DATA в архив не входят.

**Готового модифицированного BIN нет. Пакет нельзя устанавливать в приставку через USB-обновление.** Он предназначен для разработки; проверки устройства, восстановления и воспроизведения ещё не завершены.
