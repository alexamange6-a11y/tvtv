В архиве находятся первоначальные материалы, исходники, инструменты, тесты, отчёты, ресурсы интерфейса, BAT-сборка для Windows 10/11 и инструкция `START_HERE_RU.md`.

Распакуйте весь архив, установите Python 3.12 с Python Launcher и выполните `build.bat`. Проверены 43 теста и Python-сборка после чистой распаковки. Сам BAT на Windows пока не проверен.

Обновление: анализатор USB-дампа с проверкой CRC и совместимости исходных байтов, а также 224-байтный CK610-finalizer инициализации меню. Загруженный пользователем дамп и содержимое его DATA в архив не входят.

**Готового модифицированного BIN нет. Пакет нельзя устанавливать в приставку через USB-обновление.** Он предназначен для разработки; проверки устройства, восстановления и воспроизведения ещё не завершены.
