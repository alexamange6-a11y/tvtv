В архиве находятся первоначальные материалы, исходники, инструменты, тесты, отчёты, ресурсы интерфейса, BAT-сборка для Windows 10/11 и инструкция `START_HERE_RU.md`.

Распакуйте весь архив, установите Python 3.12 с Python Launcher и выполните `build.bat`. В рабочей копии пройдены 53 теста; после чистой распаковки дополнительно проверены 10 тестов нового CRC/recovery-аудита и Python-сборка. Сам BAT на Windows пока не проверен.

Обновление: независимая CRC заголовка таблицы разделов подтверждена исполнением оригинального кода eCos. Добавлен аудит реальной recovery-функции загрузчика, её цикла записи и недостаточного барьера длины после чтения файла. Подробности — в `reports/UPGRADE_RECOVERY_RU.md`. Сохранены анализатор USB-дампа и 224-байтный CK610-finalizer инициализации меню. Загруженный пользователем дамп и содержимое его DATA в архив не входят.

**Готового модифицированного BIN нет. Пакет нельзя устанавливать в приставку через USB-обновление.** Он предназначен для разработки; проверки устройства, восстановления и воспроизведения ещё не завершены.
