# Romsat T8020HD — инструкции к полному пакету проекта

Это полный пакет для продолжения разработки и повторной сборки результатов. **Готовой модифицированной прошивки для установки в приставку в нём нет.** Папка `build` содержит проверенные исследовательские результаты. Не устанавливайте файлы `.cramfs` или `.ck610` через меню обновления приставки.

## Быстрый запуск в Windows 10/11

1. Распакуйте весь ZIP, например в `C:\RomsatProject`. Не запускайте BAT прямо из окна архиватора.
2. Установите **Python 3.12 для Windows** с https://www.python.org/downloads/windows/ . В установщике включите Python Launcher (`py`). Если он уже установлен, проверьте в CMD: `py -3 --version`.
3. Запустите `build.bat` в корне распакованного проекта. PowerShell и права администратора для сборки не нужны. При первом запуске требуется интернет для установки Pillow из PyPI.
4. Для просмотра ошибок откройте CMD в папке проекта и выполните `build.bat`. Не закрывайте окно до завершения команды.
5. Успешный запуск заканчивается строкой `Research artifacts built. No modified flash BIN was produced.` Результаты находятся в папке `build`.

BAT создаёт виртуальную среду `.venv`, устанавливает зависимости, выполняет тесты и собирает ресурсы/машинный callback. Исходные материалы автоматически извлекаются из **вложенного** `Romsat_T8020HD_Codex_Full_Project.zip`: этот архив оставьте рядом с `build.bat`, вручную распаковывать его не нужно.

Для обычной сборки C-SKY objdump не обязателен: проверенные листинги уже приложены. Чтобы заново получить листинги в Windows, нужен совместимый **Windows-бинарник CK610 ABI v1**, после чего в CMD:

```bat
set "CSKY_OBJDUMP=C:\tools\csky-elf-objdump.exe"
build.bat
```

Обычный MIPS objdump для этой прошивки не подходит. Запуск BAT на настоящей Windows пока не проверен; его Python-этапы и 53 теста проверены в Linux с Python 3.12.

## Что находится внутри

| Файл или папка | Назначение |
|---|---|
| `START_HERE_RU.md` | Эти краткие инструкции |
| `README_RU.md` | Подробное описание сборки, изменений и ограничений |
| `build.bat`, `requirements.txt` | Автоматическая сборка для Windows через CMD |
| `tools`, `tests` | Исходники инструментов и тесты |
| `reports` | Результаты анализа, дизассемблирование и журнал тестов |
| `Romsat_T8020HD_Codex_Full_Project.zip` | Все первоначальные наработки, исходная прошивка и референс, без изменений |
| `build/overlay` | Подготовленные XML/BMP/JPEG главного меню, YouTube и MeeCast |
| `build/menu_callback.ck610` | Новый обработчик меню: 336 байт CK610, отдельно от прошивки |
| `build/menu_create_finalizer.ck610` | 224 байта завершающей инициализации фокуса/плиток; связанный BSR описан в манифесте |
| `build/theme_RESEARCH_ONLY.cramfs` | Проверенная файловая система ресурсов; не файл USB-обновления |
| `build/patch_manifest.json` | Точные байты патча, хеши, размеры и препятствия выпуску BIN |
| `build/youtube` | Превью YouTube и экспериментальная правка версии клиента |
| `build/meecast` | Превью подключения телефона и анализ штатного сервиса MeeCast |
| `build/upgrade` | Проверки CRC таблицы и нативных блоков USB-восстановления, включая барьер длины файла |
| `SHA256SUMS.txt` | Хеш каждого файла пакета, кроме самого списка хешей |

При повторной сборке также появится `original_roundtrip.bin` — это **точно восстановленный оригинал**, а не модифицированный образ. Экспериментальная правка YouTube автоматически в eCos не устанавливается. В `build/upgrade/findings.json` сохраняются проверки независимой CRC заголовка и исходного цикла USB-восстановления; инструкции и ограничения — в `reports/UPGRADE_RECOVERY_RU.md`. Команда сборки не создаёт recovery-файл и не требует проверки на устройстве.

## Управление и iPhone

В проекте подготовлены шесть горизонтальных плиток: ТВ, YouTube, MEGOGO, IPTV, Медиаплеер, Настройки. Стрелки меняют выбор, OK вызывает штатные маршруты, EXIT/BACK возвращает назад. Кнопка **0** открывает штатный экран MeeCast. Эти изменения ещё не установлены на приставку.

Ранее использовавшаяся программа телефона называется **MeeCast**. Проверить её штатную возможность можно на заводской прошивке: iPhone и приставка должны быть в одной домашней сети, а приложению на iPhone нужно разрешить доступ к «Локальной сети». Текущая доступность нужного приложения в украинском App Store не проверена. Передача современного YouTube и работа обычной кнопки Google Cast не подтверждены. Подробности — в `reports/MEECAST_RU.md` и `reports/YOUTUBE_RU.md`.

## Почему пока нет BIN для прошивки

У пользователя нет подтверждённого способа восстановления устройства. Кроме того, не проверены работа нового GUI на приставке, возврат из приложений, воспроизведение YouTube и все проверки контейнера загрузчиком. Офлайн-тесты и правильные CRC не заменяют этих проверок. Текущий пакет предназначен для разработки; устанавливаемый BIN можно выпускать после устранения перечисленных препятствий.

Скачать пакет и просматривать инструкции можно без подключения приставки к компьютеру.
